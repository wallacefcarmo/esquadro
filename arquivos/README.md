# Esquadro

Protótipo de sistema de gestão de produção para a BNG Metalmecânica — PCP, apontamento de chão de fábrica e acompanhamento de OS por item/operação, cobrindo os quatro setores (Preparação, Soldagem, Montagem, Usinagem).

Este repositório contém **apenas o protótipo estático** (HTML/CSS/JS sem build, sem backend), usado para validar telas e fluxos com dados de demonstração da Semana 27 antes de qualquer decisão de arquitetura ou stack definitiva.

## Páginas

- `index.html` — landing com os dois links abaixo
- `mobile.html` — versão mobile-first (painel, programação semanal, apontamento do líder com troca de perfil, OS por item/operação, máquinas)
- `desktop.html` — versão desktop (sidebar fixa, tabelas de programação por setor)

## Rodar localmente

Sem dependências — abra qualquer um dos `.html` direto no navegador.

## Publicar com GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`. O link fica em `https://wallacefcarmo.github.io/esquadro/`.

## Status

Protótipo de avaliação, não é o sistema final. Decisões de stack, modelo de dados e nome do produto ainda em aberto.
